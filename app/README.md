# Wunderkammer Gotha — App

Dieses Verzeichnis enthält die React-/TypeScript-Anwendung mit Express-Backend.

Die vollständige Projektdokumentation steht in [`../README.md`](../README.md).

Webseite: <https://gotha.friedenstein.de/>

## Befehle

```bash
npm run dev        # Express + Vite im Entwicklungsmodus (Port 3000)
npm run build      # Prebuild der Daten, Typprüfung, Vite-Produktionsbuild
npm run start      # Produktionsserver (dist/ + API)
npm run prebuild   # Externe Daten holen → public/data/pois-prebuilt.json
npm run lint       # ESLint
```
